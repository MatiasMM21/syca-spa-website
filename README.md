# SYCA SPA Website

Sitio web para SYCA SPA - Servicios de electricidad automotriz y domiciliaria.

## Descripción

Este proyecto es un sitio web completo (frontend y backend) para SYCA SPA, una empresa dedicada a servicios de electricidad automotriz, domiciliaria, reparación de fallas, instalación de accesorios y automatización.

## Tecnologías Utilizadas

### Frontend
- React.js
- React Router
- Styled Components
- Axios

### Backend
- Node.js
- Express
- Nodemailer
